# النموذج الخامس - مشروع Flutter

مشروع Flutter يحتوي على واجهتين حسب المطلوب:

1. **الواجهة الأولى (حذف عنصر):** زر "حذف"، عند الضغط عليه تظهر نافذة منبثقة (Dialog) للتأكيد تحتوي على "هل أنت متأكد من الحذف؟" وزرين: "موافق" و"إلغاء".
2. **الواجهة الثانية (شريط الأيقونات):** شريط أفقي يحتوي على 4 أيقونات (الرئيسية، البحث، المفضلة، الإعدادات).

يمكنك التنقل بين الواجهتين عبر أيقونة الشبكة الموجودة أعلى يمين الواجهة الأولى.

## طريقة التشغيل

1. تأكد من تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install) على جهازك.
2. فك ضغط الملف ثم افتح المجلد في الطرفية (Terminal):
   ```bash
   cd icon_bar_app
   flutter pub get
   flutter run
   ```
3. أو افتح المشروع مباشرة في Android Studio / VS Code وشغّله على المحاكي أو جهازك.
